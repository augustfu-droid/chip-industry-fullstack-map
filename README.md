# 芯片产业链全栈技术图谱与演进架构

> 从底层物理、制造工艺到异构计算节点的深度解构 —— 完备版产业调研报告（公开版）

本仓库为芯片产业链全栈技术调研报告的**公开版本**，从技术与产业格局视角出发，覆盖从材料、设计、制造、封装、互连、存储、计算架构、软件栈到应用与地缘政治的完整十卷四十章框架。

公开版**不包含具体投资标的与股票代码**，仅供个人研究与技术学习交流，不构成任何投资建议。

## 关键技术议题

- CMOS 2.0 与韬（τ）定律：从几何缩微到时间缩微
- GAAFET / CFET / BSPDN 先进制程
- EUV / High-NA 光刻
- CoWoS / Foveros / 混合键合 / 玻璃基板
- HBM4 → HBM5 高带宽存储演进
- 共封装光学（CPO）与硅光产业
- CXL / PIM 存算融合
- CPU / GPU / TPU / NPU / 晶圆级 / 类脑 / 光子 / 量子异构计算
- 地缘政治与产业政策
