## 本地复现图表

环境要求：Python 3.10+、Matplotlib、NumPy，以及至少一套覆盖中文字符的字体。脚本优先使用 Noto Sans CJK / 思源黑体，并兼容常见 macOS 和 Windows 中文字体；若找不到可用中文字体会明确失败，避免静默生成方框字。

`requirements.txt` 固定了本次维护验证所用的 Matplotlib 与 NumPy 版本。仓库没有打包字体文件，因此不同系统选择不同中文字体时，文字布局和 PNG 哈希仍可能略有差异；如需字节级复现，还需使用同一字体文件。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

# 查看图表标识
python gen_figures.py --list

# 默认重建全部图表到 figures/
python gen_figures.py

# 只生成单张图，也可指定目录和 DPI
python gen_figures.py --figure litho-roadmap --output-dir /tmp/chip-map --dpi 200
```

运行仓库完整性检查：

```bash
npm test
```

## 本地复现 PDF

PDF 构建器使用 Marked 17.0.5 将 Markdown 转为 HTML，再由 WeasyPrint 68.1 输出带书签、内部链接和嵌入字体的 A4 PDF。默认同时写入版本化产物和仓库根目录兼容入口：

```bash
# 在上面的 Python 虚拟环境中安装 WeasyPrint、Pillow 与 pypdf
python -m pip install -r requirements.txt

# 安装 Markdown 解析器并生成 PDF
npm install
npm run build:pdf

# 逐页渲染、生成联系表并检查页数、缺字、章节和 13 张图
python scripts/qa_pdf.py
```

正式产物位于 `output/pdf/芯片产业链全栈技术图谱_公开版_v1.12-public.pdf`，兼容入口为仓库根目录同名 PDF；中间 HTML、逐页渲染图和联系表保存在已忽略的 `tmp/pdfs/`。如系统没有 Poppler，请先安装 `pdftoppm`，或通过 `--pdftoppm` 指定其路径。
